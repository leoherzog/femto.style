Plain CSS, no build step

femto is plain CSS, with no Sass and no build step to use or customize it. dist/femto.min.css holds all of femto in one file, with no JavaScript.

Get started→

⚙️

One file per theme or option

Azure is built in. Each of the 19 other theme colors and each of the 3 options is one more file to link, and --femto-* custom properties change the rest.

See the theme colors→

◐

Light and dark color schemes

femto picks each color with CSS's light-dark(), so it follows the visitor's system setting (prefers-color-scheme) without JavaScript. data-theme chooses a scheme for the whole page or for one element.

Learn about the color schemes→

Wide compatibility

Runs on Baseline Widely Available browser versions from the last few years, with sensible fallbacks. Your site looks great in Chrome, Firefox and Safari.

Semantic HTML, few classes

femto styles your HTML elements directly. A few classes cover what HTML has no element for, such as .container and .grid for layout and .secondary, .contrast and .outline for button styles.

See the classes and attributes→

⤢

Responsive by default

The root font size steps up at 576, 768, 1024, 1280 and 1536px, so text and spacings grow with the screen. One option keeps the font size fixed, and another adds more spacing at each breakpoint.
