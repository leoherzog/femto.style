Examples

Widgets, forms and pages built with femto alone.

Each example is plain HTML styled by femto alone: it uses HTML's elements and only the classes and attributes femto reads. It renders in a shadow root that loads dist/femto.min.css and nothing else, so none of this site's CSS reaches it. Open the markup under an example to copy its HTML.

Blog post

An article with a byline, a list, a quotation and a code block.

Markup of the blog post 
<hgroup>
  <h3>How we cut our page weight in half</h3>
  <p>By Alex Kim, <time datetime="2026-10-28">October 28, 2026</time></p>
</hgroup>
<p>Our pages had grown to 2 MB. Most of it was styles and scripts that no visitor needed, so we started again with plain HTML and one stylesheet.</p>
<h4>What we removed</h4>
<ul>
  <li>A front-end framework that only two pages used</li>
  <li>Three icon fonts, replaced by inline SVG</li>
  <li>Hundreds of <abbr title="Cascading Style Sheets">CSS</abbr> classes that no page used</li>
</ul>
<blockquote>
  Every byte we send is a byte someone waits for.
  <footer>
    <cite>Our performance team</cite>
  </footer>
</blockquote>
<h4>Try it yourself</h4>
<p>Build the site, then compare the page sizes in your browser's developer tools.</p>
<pre><code>npm run build</code></pre>
<p>The new pages load in under a second on a slow connection. <mark>Every page now weighs less than 500 KB.</mark></p>
<hr>
<p><small>Filed under <a href="#">Performance</a> and <a href="#">Engineering</a>.</small></p>
