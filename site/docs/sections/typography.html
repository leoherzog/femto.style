Typography

The root font size steps up at each breakpoint, and text elements are sized relative to it, so text grows with the screen.

The root font size, --femto-font-size on :root, is a percentage, so it follows the visitor's own default font size. It steps up at each breakpoint, from 100% to 131.25%.

Headings and other elements are sized in rem, a multiple of the root font size, and <small>, <sub>, <sup> and code in em, a multiple of the text around them.

To keep the root font size at 100% at every width, load the css/options/fixed-typography.css option.

Heading group

Inside an <hgroup>, the elements have no margins, and the last one, after the heading, is muted.

Plain CSS for semantic HTML

The paragraph after the heading is muted.

<hgroup>
  <h2>Plain CSS for semantic HTML</h2>
  <p>The paragraph after the heading is muted.</p>
</hgroup>
