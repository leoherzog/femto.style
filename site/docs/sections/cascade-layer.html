Cascade layer

femto is not in a cascade layer: to put it in one, import it with layer(), with your theme and option files in the same layer.

The paths below are relative to femto's css/ folder, and your own rules follow the imports, unlayered:

@import url(femto.css) layer(femto);
@import url(themes/jade.css) layer(femto);
@import url(options/no-transitions.css) layer(femto);

If you install femto from npm, use package paths instead:

@import "@leoherzog/femto/css/femto.css" layer(femto);
@import "@leoherzog/femto/css/themes/jade.css" layer(femto);
@import "@leoherzog/femto/css/options/no-transitions.css" layer(femto);

Your unlayered rules then override femto's, whatever their specificity, except femto's few !important declarations.

Theme and option files belong in femto's layer. Left unlayered, they would compete with your unlayered rules by specificity instead of always losing to them, and would override any rules you put in layers of your own.

dist/femto.min.css can be imported into a layer the same way, and it loads as one file (see Files).
