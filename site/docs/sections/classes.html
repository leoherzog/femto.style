Getting started

Classes and attributes

Most of femto works from the elements alone; these are the classes and attributes it also reads.

Link femto and plain HTML is styled: headings, text, links, buttons, forms, tables, cards (<article>), accordions (<details>) and modals (<dialog>) need no classes. A few classes and attributes cover what HTML has no element for. Most rows link to the section that shows them in full.

Layout

Markup What it does
.container, .container-fluid Centers the content at a maximum width for each breakpoint, or spans the full width. See Container.
.grid Lays its children out in equal columns from 768px, in one column below. See Grid.
.overflow-auto Scrolls content that overflows it, such as a wide table. See Overflow auto.

Buttons and links

Markup What it does
.secondary, .contrast, .outline Button styles; .secondary and .contrast also color links. See Button and Link.
role="button" An element that looks like a button, such as a link or a <summary>. See Button.
role="link" An element that looks like a link.

Forms

Markup What it does
<input type="checkbox" role="switch"> A switch. See Switch.
aria-invalid="true" or "false" on a form field Invalid or valid border colors, an icon in most text fields, and a matching color on a <small> right after the field. See Input.
role="group", role="search" Joins buttons, inputs and selects in one row; search rounds the ends. See Group.

Components

Markup What it does
<details class="dropdown"> A dropdown: a <summary> and a <ul> that opens below it. See Dropdown.
<nav aria-label="breadcrumb"> Breadcrumbs. See Nav.
aria-busy="true" A loading spinner. See Loading.
data-tooltip, data-placement A tooltip with that text, above the element or where data-placement (top, bottom, left, right) puts it. A switch shows none, since its ::before is its thumb, so put the tooltip on the switch's <label>. See Tooltip.
<dialog> holding an <article> A modal. The .modal-is-open, .modal-is-opening and .modal-is-closing classes, which your script sets on <html>, lock scrolling and run the opening and closing animations. To keep the page from shifting when .modal-is-open hides the scrollbar, your script can also set --femto-scrollbar-width on <html> to the scrollbar's width. See Modal.
.close, or rel="prev" on a link or button, in a modal's <article> A close button: an × icon at the top right (top left in right-to-left text), in the header if there is one. See Modal.

States

Markup What it does
aria-current (any value but "false") Shows a link, button or dropdown item as current, with its hover colors; in breadcrumbs, the current page as plain text. See Link.
disabled, aria-disabled="true" A not-allowed cursor; aria-disabled="true" on a <label> also dims it like a disabled field.
aria-controls A pointer cursor.

The current page and another page

<a href="#" aria-current="page">The current page</a>
<a href="#">another page</a>

<label aria-disabled="true">
  <input type="checkbox" name="unavailable" disabled>
  Not available
</label>

Direction

Markup What it does
dir="rtl" Right-to-left text, with the form field icons, chevrons, breadcrumb separators, group and search corners, progress animation, modal close button and modal footer mirrored. See RTL.
