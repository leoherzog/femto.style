Reference

Classes and attributes

Most of femto works from the elements alone; these are the classes and attributes it also reads.

Headings, text, links, buttons, forms, tables, cards (<article>), accordions (<details>) and modals (<dialog>) need no classes. The classes and attributes below cover what HTML has no element for.

Layout

Markup What it does
.container, .container-fluid Centers the content at a maximum width for each breakpoint, or spans the full width. See Container.
.grid Lays its children out in equal columns from 768px, in one column below. See Grid.
.overflow-auto Scrolls content that overflows it, such as a wide table. See Overflow auto.

Buttons and links

Markup What it does
.secondary, .contrast, .outline Button styles; .secondary and .contrast also color links. See Button and Link.
role="button" An element that looks like a button, such as a link or a <summary>. See Button.
role="link" An element that looks like a link.

Tables

Markup What it does
<table class="striped"> Shades the odd body rows, not counting rows with the hidden attribute. See Table.

In this table the second row is hidden, so the rows you see keep alternating:

Planet Moons
Mercury 0
Venus 0
Earth 1
Mars 2 
<table class="striped">
  <thead>
    <tr><th scope="col">Planet</th><th scope="col">Moons</th></tr>
  </thead>
  <tbody>
    <tr><td>Mercury</td><td>0</td></tr>
    <tr hidden><td>Venus</td><td>0</td></tr>
    <tr><td>Earth</td><td>1</td></tr>
    <tr><td>Mars</td><td>2</td></tr>
  </tbody>
</table>

Forms

Markup What it does
<input type="checkbox" role="switch"> A switch. See Switch.
aria-invalid="true" or "false" on a form field Invalid or valid colors on the field and its helper text. See Input.
role="group", role="search" Joins buttons, inputs and selects in one row; search rounds the ends. See Group.

Components

Markup What it does
<details class="dropdown"> A dropdown: a <summary> and a <ul> that opens below it. See Dropdown.
<nav aria-label="breadcrumb"> Breadcrumbs. See Nav.
aria-busy="true" A loading spinner. See Loading.
data-tooltip, data-placement A tooltip with that text; data-placement sets its side. See Tooltip.
<dialog> holding an <article> A modal; your script sets its opening and closing classes on <html>. See Modal.
.close, or rel="prev" on a link or button, in a modal's <article> A close button for the modal. See Modal.

States

Markup What it does
aria-current (any value but "false") Shows a link, button or dropdown item as current, with its hover colors; in breadcrumbs, the current page as plain text. See Link.
disabled, aria-disabled="true" A not-allowed cursor; aria-disabled="true" on a <label> also dims it like a disabled field.
aria-controls A pointer cursor.

utilities/accessibility.css sets these cursors, and direction for dir="rtl". It also gives an element with both hidden and aria-hidden="false" a display and clips it while it does not have focus, but femto's [hidden] rule still hides it.

Direction

Markup What it does
dir="rtl" Right-to-left text, with femto's directional parts mirrored. See RTL.
