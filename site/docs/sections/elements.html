Reference

Elements

femto styles HTML elements by their names, so the elements are its API. This is what it does to each one.

The few classes and attributes it also reads are in Classes and attributes, and its custom properties in Tokens. To see most of these elements on one page, open the Every element example.

Element and its section What femto does
Page
<html>
Typography		 Gives the page its background, text color, font, root font size and line height
<body>
Landmarks and sections		 Fills the width, with no margin
<header>, <main>, <footer> in <body>
Landmarks and sections		 Vertical padding
<section>
Landmarks and sections		 A bottom margin
<nav>
Nav		 A row of unstyled lists whose links, buttons and fields line up; a column in <aside>
<article>
Card		 A card: padding, rounded corners, a background and a shadow
<header>, <footer> in <article>
Card		 Reach the card's edges, with their own background and a border
<dialog>
Modal		 A modal: an overlay over the viewport, with its <article> centered
Text
<h1> to <h6>
Typography		 A size, weight, color and line height for each, and space above one that follows a text block, list, table, figure, form or card
<hgroup>
Typography		 No margins inside it; the last element after the heading is muted
<p>, <address>
Typography		 A bottom margin; <address> is not italic
<a>
Link		 The primary color, an underline and a focus ring
<b>, <strong>
Typography		 Bolder
<small>
Typography		 0.875em
<sub>, <sup>
Typography		 0.75em, without changing the line height
<abbr title>
Typography		 A dotted underline and a help cursor
<mark>
Typography		 A highlight
<ins>, <del>
Typography		 Their own colors; <ins> has no underline
<blockquote>
Typography		 Padding and a border at the start; its <footer> is muted
<hr>
Typography		 A muted line
<ul>, <ol>, <dl>
Media, code and lists		 Space between the items of <ul> and <ol>, and square markers in <ul>; a nested list has only a small top margin. <dt> and <dd> keep the browser's styles
<pre>, <code>, <samp>
Media, code and lists		 The monospace font in the code colors; <pre> scrolls
<kbd>
Media, code and lists		 Bolder monospace, in the text color as its background
Media
<figure>, <figcaption>
Media, code and lists		 No margin or padding; a muted caption
<img>
Media, code and lists		 Scales down to its container
<svg>
Media, code and lists		 The text color, unless it has a fill
<audio>, <video>, <canvas>
Media, code and lists		 Inline blocks; <audio> without controls is hidden
<iframe>
Media, code and lists		 No border
<template>
Media, code and lists		 Never shown, like an element with hidden
Tables
<table>, <th>, <td>
Table		 Full width, with padded cells and a border under each
<thead>, <tfoot>
Table		 Bolder cells with a wider border
Forms
<button>, <input type="submit">, "button", "reset"
Button		 A button in the primary color
<label>
Forms overview		 A block above its field; beside a checkbox or radio
<input>
Input		 A full-width field with focus, disabled and validation states
<input type="search">, "date", "time", "color", "file"
Input		 Rounded ends and a magnifier, a calendar or clock icon, a bare swatch, a compact button
<input type="checkbox">
Checkboxes		 A redrawn box with a check or minus; a switch with role="switch"
<input type="radio">
Radios		 A redrawn circle with a dot
<input type="range">
Range		 A thin track and a round thumb
<select>, <optgroup>, <option>
Select		 A field with a chevron; with multiple, shaded chosen options
<textarea>
Textarea		 A field that resizes vertically
<fieldset>, <legend>
Forms overview		 No border or padding; the legend as a label
<small> after a field
Forms overview		 Muted helper text, or the <ins> or <del> color with the field's aria-invalid
Components
<details>, <summary>
Accordion		 An accordion: a summary with a chevron that turns as it opens
<progress>
Progress		 A rounded bar; without a value, a sliding stripe
