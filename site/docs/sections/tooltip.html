Tooltip

data-tooltip shows its text in a tooltip on hover and focus, without JavaScript.

Tooltip on a link

Tooltip on an inline element

<p>Tooltip on a <a href="#" data-tooltip="Tooltip">link</a></p>
<p>Tooltip on an <em data-tooltip="Tooltip" tabindex="0">inline element</em></p>
<p><button type="button" data-tooltip="Tooltip">Tooltip on a button</button></p>

Elements other than links, buttons, inputs and role="button" also get a dotted underline and a help cursor. Give an element that cannot take focus, such as an <em>, tabindex="0" so its tooltip shows from the keyboard.

Placement

The tooltip shows above the element, or where data-placement puts it: top, bottom, left or right.

<button type="button" data-tooltip="Top">Top</button>
<button type="button" data-tooltip="Right" data-placement="right">Right</button>
<button type="button" data-tooltip="Bottom" data-placement="bottom">Bottom</button>
<button type="button" data-tooltip="Left" data-placement="left">Left</button>

Switch

A switch shows no tooltip; put it on the switch’s <label> instead: see Switch.

Used in the Dashboard example.
