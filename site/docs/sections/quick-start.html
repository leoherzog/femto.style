Getting started

Quick start

Semantic HTML made beautiful: link one stylesheet and plain HTML looks clean and readable, with no classes needed. femto builds on Pico CSS.

Compared to Pico CSS, femto:

  • Uses plain CSS, with modules joined by @import, instead of Sass
  • Uses CSS variables for theme colors, one small file per color, instead of a compiled copy of the library for each
  • Uses add-on files instead of Sass variables for its options
  • Uses CSS's light-dark() for the light and dark color schemes
  • Drops the rarely used classless, fluid classless and conditional builds

For every change, see Migrating from Pico.

The @3 links and commands in these docs work once 3.0.0 is released, since jsDelivr and npm skip prereleases for @3. Until then, load the alpha by its version, or write @alpha in place of @3:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@{{version}}/dist/femto.min.css">

From npm, install it pinned to its exact version, since a later alpha may rename things:

npm install --save-exact @leoherzog/femto@alpha

From a CDN

Link femto from jsDelivr in the <head> of your page:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">

Download

Download femto and link dist/femto.min.css:

<link rel="stylesheet" href="dist/femto.min.css">

npm

npm install @leoherzog/femto

The package's main file is dist/femto.min.css, and it exports every file in css/ and dist/ by its path, such as @leoherzog/femto/css/themes/jade.css. In a CSS file that a bundler processes, import it by those paths:

@import "@leoherzog/femto";
@import "@leoherzog/femto/css/themes/jade.css";

A bundler that rewrites CSS for older browsers can break femto's color schemes. Vite 8's production build, for example, minifies CSS with Lightning CSS for browsers older than femto supports, and rewrites every light-dark() into variables that resolve once on :root, so data-theme on an element no longer changes its colors. Set the bundler's CSS targets to femto's minimum versions. In Vite, set build.cssTarget in vite.config.js to ["chrome125", "edge125", "firefox128", "safari17.5", "ios17.5"].

List ios17.5 as well as safari17.5: without it, Lightning CSS drops -webkit-text-size-adjust, the only form iOS Safari reads. Vite does not accept a Samsung Internet target, and chrome125 covers Samsung Internet 27, which is built on Chromium 125.

Starter template

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="color-scheme" content="light dark">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
    <title>Hello, world!</title>
  </head>
  <body>
    <main class="container">
      <h1>Hello, world!</h1>
    </main>
  </body>
</html>

To add a theme color or options, let the Theme picker write the links, or see Themes and Options.
