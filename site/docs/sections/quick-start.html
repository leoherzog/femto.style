Getting started

Quick start

Link femto.css manually or via CDN for a dependency-free setup, or use NPM or Composer for advanced usage.

There are 4 ways to get started with femto:

Install manually

Download femto and link /dist/femto.min.css in the <head> of your website.

<link rel="stylesheet" href="dist/femto.min.css">

Usage from CDN

Alternatively, you can use jsDelivr CDN to linkfemto.min.css.

<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css"
>

Install with NPM

npm install @leoherzog/femto

Or

yarn add @leoherzog/femto

Then, import Pico into your SCSS file with @use:

@use "pico";

Learn more about the customization with Sass.

Install with Composer

composer require leoherzog/femto

Starter HTML template

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="color-scheme" content="light dark">
    <link rel="stylesheet" href="dist/femto.min.css">
    <title>Hello world!</title>
  </head>
  <body>
    <main class="container">
      <h1>Hello world!</h1>
    </main>
  </body>
</html>
