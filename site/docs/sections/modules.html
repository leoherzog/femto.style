Customization

Custom module set

To load only some modules, save a copy of css/femto.css in the same folder and delete the lines you do not need.

The copy must sit in the same folder as css/femto.css, under a name of your own such as site.css, since its @import paths are relative to it. After its header comment, it holds 36 @import lines, one for each module:

@import "tokens/base.css";
@import "tokens/breakpoints.css";
@import "layout/elements.css";
@import "tokens/schemes.css";
@import "layout/document.css";
@import "layout/landmarks.css";
@import "layout/section.css";
@import "layout/container.css";
@import "layout/grid.css";
@import "layout/overflow-auto.css";
@import "content/typography.css";
@import "content/link.css";
@import "content/button.css";
@import "content/table.css";
@import "content/embedded.css";
@import "content/code.css";
@import "content/figure.css";
@import "content/misc.css";
@import "forms/basics.css";
@import "forms/checkbox-radio-switch.css";
@import "forms/input-color.css";
@import "forms/input-date.css";
@import "forms/input-file.css";
@import "forms/input-range.css";
@import "forms/input-search.css";
@import "components/accordion.css";
@import "components/card.css";
@import "components/dropdown.css";
@import "components/group.css";
@import "components/loading.css";
@import "components/modal.css";
@import "components/nav.css";
@import "components/progress.css";
@import "components/tooltip.css";
@import "utilities/accessibility.css";
@import "utilities/reduce-motion.css";

Keep the lines in their order, which is the cascade order, and keep the first four: tokens/base.css, tokens/breakpoints.css, layout/elements.css and tokens/schemes.css. They hold the tokens and per-element settings the other modules read. Without layout/elements.css, for example, headings lose their sizes and weights, and search fields their rounded ends.

The copy loads module by module, like css/femto.css (see Files). A bundler that inlines @import turns it into one file.

If you install femto from npm, write the same list in your own CSS with package paths, such as @import "@leoherzog/femto/css/tokens/base.css";, instead of copying the file.

If you also load no-transitions.css, copy it too and delete its rules for the modules you left out (see Options).
