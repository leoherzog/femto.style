Options

Each option is one more file, loaded after the theme. The switches apply it to this page and add it to the code below. These docs start with responsive spacings on.

Apply to this page and the code below More spacing at each breakpoint for the page's header, main, and footer, its sections, and its cards. The root font size stays at 100% at every width. Turns off transitions and the modal and tooltip animations; the loading spinner and the indeterminate progress bar still animate.

Links to copy

Link these in the <head> of your page, in this order: femto, the theme, the options, then your own stylesheets. Azure is built in, so it needs no theme file.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/css/options/responsive-spacings.css">
<link rel="stylesheet" href="styles.css">

Until 3.0.0 is released, write @{{version}} or @alpha in place of @3 (see Quick start).

One request

The same files in one request, as a jsDelivr combine URL; with azure and no options, it is femto's plain link:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/combine/npm/@leoherzog/femto@3/dist/femto.min.css,npm/@leoherzog/femto@3/css/options/responsive-spacings.css">

Starter template

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <meta name="color-scheme" content="light dark">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/css/options/responsive-spacings.css">
    <title>Hello, world!</title>
  </head>
  <body>
    <main class="container">
      <h1>Hello, world!</h1>
    </main>
  </body>
</html>
