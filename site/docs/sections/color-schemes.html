Customization

Color schemes

femto has a light and a dark color scheme, which follow the visitor's system setting unless you choose one with data-theme.

By default, femto follows the visitor's system setting (prefers-color-scheme) on screen, and prints in the light scheme. To choose a scheme, set data-theme="light" or data-theme="dark" on <html> for the whole page, or on one element for a part of it.

<html lang="en" data-theme="dark">

On an element

On an element, data-theme switches the colors femto sets on it and inside it, such as a card's background and the colors of headings, paragraphs, links, buttons, and form fields:

A light card

This card and the text in it use the light scheme, whatever the rest of the page uses.

<article data-theme="light">
  <h2>A light card</h2>
  <p>This card and the text in it use the light scheme, whatever the rest of the page uses.</p>
  <form>...</form>
</article>

A dark card

This card and the text in it use the dark scheme, whatever the rest of the page uses.

<article data-theme="dark">
  <h2>A dark card</h2>
  <p>This card and the text in it use the dark scheme, whatever the rest of the page uses.</p>
  <form>...</form>
</article>

It does not change the color the element inherits, so text directly inside it keeps that color, and it adds no background to an element femto gives none, such as a <section> or a <div>. Where you need them, set the color on the element yourself, and the background too if femto gives it none:

section[data-theme] {
  background-color: var(--femto-background-color);
  color: var(--femto-color);
}

How it works

Every color token is declared once, on :root and :host. A token that femto or a theme gives a light and a dark value takes them from a pair of tokens of its own: --femto-primary is light-dark(var(--femto-light-primary), var(--femto-dark-primary)). Other color tokens have no pair: those with one value, such as --femto-primary-background, and those set from another token, such as --femto-primary-hover-underline, which follows --femto-primary-hover in each scheme. --femto-box-shadow uses light-dark() in each of its layers. data-theme sets color-scheme, which picks between the two values, plus the form validation icons, which light-dark() cannot carry. So:

  • An element that carries data-theme itself, such as a button, heading, or form field, keeps its own colors in that scheme.
  • Your own color overrides on :root, loaded after femto, apply inside every data-theme element. Set a token's pair to give each scheme its own value, or one of the two to change one scheme. A plain value of the token itself, such as --femto-primary: #c00, applies in both schemes, in place of its pair.
  • data-theme="dark" on a web component's host makes its shadow root dark when the component loads femto there. See Shadow roots.

For example, this override gives the page a background of your own in each scheme:

:root {
  --femto-light-background-color: #fffdf7;
  --femto-dark-background-color: #101418;
}

femto combines each pair into its token on :root and :host, so a --femto-light-* or --femto-dark-* token set on another element does not change femto's colors. To change a color in one part of a page, set the token itself on that element, such as --femto-primary on a card. CSS variables has more on overrides, and links to the files that declare the tokens' defaults.

Browsers without light-dark() get the light scheme only, and bundlers that rewrite it break color schemes: see Browser support.

The color-scheme property

A color-scheme that your own CSS sets on an element also switches femto's colors in that subtree, as it switches the browser's own colors:

aside {
  color-scheme: dark;
}

data-theme is still the way to theme an element: it also switches the form validation icons, which light-dark() cannot carry.

Forced colors

In forced colors mode, such as a Windows contrast theme, the browser replaces femto's colors with the system's. femto then draws focus as a Highlight outline, and the state of checkboxes, radios, and switches and the tracks of <progress> and range sliders in system colors.
