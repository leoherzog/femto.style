Getting started

Color schemes

femto has a light and a dark color scheme, which follow the visitor's system setting unless you choose one with data-theme.

By default, femto follows the visitor's system setting (prefers-color-scheme) on screen, and prints in the light scheme. To choose a scheme, set data-theme="light" or data-theme="dark" on <html> for the whole page, or on one element for a part of it.

<html lang="en" data-theme="dark">

On an element

On an element, data-theme switches the colors femto sets on it and inside it, such as a card's background and the colors of headings, paragraphs, links, buttons and form fields:

A light card

This card and the text in it use the light scheme, whatever the rest of the page uses.

<article data-theme="light">
  <h2>A light card</h2>
  <p>This card and the text in it use the light scheme, whatever the rest of the page uses.</p>
  <form>...</form>
</article>

A dark card

This card and the text in it use the dark scheme, whatever the rest of the page uses.

<article data-theme="dark">
  <h2>A dark card</h2>
  <p>This card and the text in it use the dark scheme, whatever the rest of the page uses.</p>
  <form>...</form>
</article>

It does not change the text color the element inherits, which text directly inside it keeps, and it adds no background to an element femto gives none, such as a <section> or a <div>. Where you need them, set color: var(--femto-color) on the element, and background-color: var(--femto-background-color) if femto gives it no background:

section[data-theme] {
  background-color: var(--femto-background-color);
  color: var(--femto-color);
}

How it works

Every color token is declared once, on :root and :host, with light-dark() where the light and dark values differ. data-theme sets color-scheme, which picks between them, plus the few values light-dark() cannot carry: the form validation icons, and the chevron and loading spinner on .contrast buttons. So:

  • An element that carries data-theme itself, such as a button, heading or form field, keeps its own colors in that scheme.
  • Your own color overrides on :root, loaded after femto, apply in both schemes and inside every data-theme element. Write them with light-dark() to give each scheme its own value.
  • data-theme="dark" on a web component's host makes its shadow root dark when the component loads femto there. See Shadow roots.

For example, this override gives the page a background of your own in each scheme:

:root {
  --femto-background-color: light-dark(#fffdf7, #101418);
}

CSS variables links to the files that declare every token.

The color-scheme property

A color-scheme that your own CSS sets on an element also switches femto's colors in that subtree, as it switches the browser's own colors:

aside {
  color-scheme: dark;
}

data-theme is still the way to theme an element: it also switches the form validation icons and the chevron and loading spinner on .contrast buttons, which light-dark() cannot carry.

Older browsers and bundlers

Color schemes rely on light-dark(), which all of femto's supported browsers have. Browsers without it get a broken femto, and tools that rewrite it stop data-theme from working on an element: see Browser support, and set a bundler's CSS targets as Quick start shows under npm.
