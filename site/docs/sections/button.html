Button

A plain <button> needs no class and has the primary color by default.

<button type="button">Button</button>

A button is at most as wide as its container, so a long label wraps.

Variants

.secondary and .contrast give a button the secondary or contrast color.

<button type="button" class="secondary">Secondary</button>
<button type="button" class="contrast">Contrast</button>

.outline draws a button as an outline, alone or with .secondary or .contrast.

<button type="button" class="outline">Primary</button>
<button type="button" class="outline secondary">Secondary</button>
<button type="button" class="outline contrast">Contrast</button>

Form buttons

Inputs with type="submit", "button" or "reset" look like buttons. Like the other form fields, they fill the width of their container, and so does a <button type="submit">.

<input type="submit">
<input type="button" value="Input">

A reset input has the secondary color by default.

<input type="reset">

Disabled

A button with disabled, or inside a disabled <fieldset>, is dimmed and takes no clicks.

<button type="button" disabled>Disabled</button>
<button type="button" class="secondary" disabled>Disabled</button>
<button type="button" class="contrast" disabled>Disabled</button>

Role button

role="button" makes another element, such as a link or a <summary>, look like a button.

Div as a button
<div role="button" tabindex="0">Div as a button</div>

Usage with group

To join buttons in one row, use role="group".
