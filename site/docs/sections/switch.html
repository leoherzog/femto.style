Forms

Switch

<input type="checkbox" role="switch"> is a switch: a checkbox drawn as a sliding toggle.

Preferences: 
<fieldset>
  <legend>Preferences:</legend>
  <label>
    <input name="terms" type="checkbox" role="switch">
    I agree to the Terms
  </label>
  <label>
    <input name="opt-in" type="checkbox" role="switch" checked>
    I want to receive updates
  </label>
</fieldset>

Disabled

aria-disabled="true" on the label of a disabled switch dims the label too.

Account settings: 
<fieldset>
  <legend>Account settings:</legend>
  <label aria-disabled="true">
    <input name="publish" type="checkbox" role="switch" disabled>
    Publish on my profile
  </label>
  <label aria-disabled="true">
    <input name="change-password" type="checkbox" role="switch" checked disabled>
    Change my password at next login
  </label>
</fieldset>

Validation states

aria-invalid="true" or "false" gives a switch the invalid or valid border color, and fills it with that color when it is on.

Security and billing: 
<fieldset>
  <legend>Security and billing:</legend>
  <label>
    <input name="2fa" type="checkbox" role="switch" aria-invalid="false">
    Enable two-factor authentication
  </label>
  <label>
    <input name="subscription" type="checkbox" role="switch" aria-invalid="true">
    Automatic subscription renewal
  </label>
</fieldset>

Tooltip

A switch shows no tooltip, since its ::before is its thumb. Put data-tooltip on its <label> instead. See Tooltip.

<label data-tooltip="We send a code to your phone">
  <input name="sms" type="checkbox" role="switch">
  Text me a sign-in code
</label>
