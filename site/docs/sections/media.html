Media, code and lists

Images scale down to fit, figures get a muted caption, code blocks scroll, and nested lists sit closer together.

Figure

A <figure> has no margin or padding, and its <figcaption> gets vertical padding in the muted color. An <img> is never wider than its container, and keeps its aspect ratio as it shrinks.

<figure>
  <img src="card.png" alt="..." width="1200" height="630">
  <figcaption>
    A 1200px image, scaled down to the card.
  </figcaption>
</figure>

Embedded content

<audio>, <canvas>, <iframe>, <img>, <svg> and <video> sit on the middle of the line. Audio, video and canvas are inline blocks, an iframe has no border, and an <audio> without controls is hidden. An inline <svg> without a fill takes the text color:

<p>
  <svg width="24" height="24" viewBox="0 0 24 24" aria-hidden="true">
    <circle cx="12" cy="12" r="10"></circle>
  </svg>
  Text
  <ins><svg ...>...</svg> Inserted</ins>
  <del><svg ...>...</svg> Deleted</del>
</p>

<video src="clip.mp4" controls></video>
<audio src="song.mp3" controls></audio>
<iframe src="map.html" title="Map"></iframe>

<template> and every element with hidden stay hidden, whatever display other rules give them.

Code blocks

<pre>, <code>, <kbd> and <samp> are in the monospace font, --femto-font-family-monospace, at 0.875em. A <pre> is a block in the code colors that scrolls sideways, and its <code> or <samp> child carries the padding. <kbd> is bolder, in the text color as its background.

<main class="container">
  <h1>Hello, world!</h1>
</main>
$ echo "Hello, world!"
Hello, world!

Press Ctrl + C to copy.

<pre><code>&lt;main class="container"&gt;
  &lt;h1&gt;Hello, world!&lt;/h1&gt;
&lt;/main&gt;</code></pre>

<pre><samp>$ echo "Hello, world!"
Hello, world!</samp></pre>

<p>Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy.</p>

The code blocks elsewhere in these docs are the site's own, with highlighting and a copy button.

Lists

List items are a quarter of --femto-typography-spacing-vertical apart. A list inside a list has no margin but that quarter above it. Items of a <ul> have square markers.
