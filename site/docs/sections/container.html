Container

Use .container to center the content at a maximum width for each breakpoint, or .container-fluid to span the full width.

femto's breakpoints are fixed at 576, 768, 1024, 1280 and 1536px. At each one, .container takes a wider maximum width.

Size Viewport width Maximum width
xs <576px 100%
sm ≥576px 510px
md ≥768px 700px
lg ≥1024px 950px
xl ≥1280px 1200px
xxl ≥1536px 1450px

Both classes have a side padding of --femto-spacing, 1rem by default: .container-fluid at every width, .container only below 576px.

Centered

.container centers its content at the maximum width of the current breakpoint. Put it on the page's <header>, <main> and <footer>, or on any other element.

<body>
  <header class="container">...</header>
  <main class="container">...</main>
  <footer class="container">...</footer>
</body>

Full width

.container-fluid spans the full width at every breakpoint.

<body>
  <main class="container-fluid">
    ...
  </main>
</body>
