Modal

A <dialog> holding an <article> is a modal: a card centered over the page.

The dialog covers the viewport with an overlay. A .close element, or a link or button with rel="prev", in the card is a close button: an × icon at the top right, or the top left in right-to-left text. In a <header>, it lines up with the title.

🗓️ Thank you for registering!

We’re excited to have you join us for our upcoming event. Please arrive at the museum on time to check in and get started.

  • Date: Saturday, April 15
  • Time: 10:00am - 12:00pm
 
<dialog open>
  <article>
    <header>
      <button type="button" aria-label="Close" rel="prev"></button>
      <p>
        <strong>🗓️ Thank you for registering!</strong>
      </p>
    </header>
    <p>
      We’re excited to have you join us for our
      upcoming event. Please arrive at the museum
      on time to check in and get started.
    </p>
    <ul>
      <li>Date: Saturday, April 15</li>
      <li>Time: 10:00am - 12:00pm</li>
    </ul>
  </article>
</dialog>

The card’s <footer> aligns its content to the end: right, or left in right-to-left text.

Opening and closing

A dialog shows when it has the open attribute, which the HTMLDialogElement methods show() and showModal() set. femto has no JavaScript: your script opens and closes the modal, and sets three classes on <html> that lock scrolling and run the animations:

  • .modal-is-open while a modal is open: the page behind it does not scroll and ignores the pointer.
  • .modal-is-opening with it, during the opening animation.
  • .modal-is-closing with it, during the closing animation.

.modal-is-open hides the page’s scrollbar; to keep the page from shifting, also set --femto-scrollbar-width on <html> to the scrollbar’s width. This script does all of it:

<button type="button" data-target="membership">Open modal</button>

<dialog id="membership" aria-labelledby="membership-title">
  <article>
    <h2 id="membership-title">Confirm your membership</h2>
    <p>...</p>
    <footer>
      <button type="button" class="secondary" data-close>Cancel</button>
      <button type="button" data-close>Confirm</button>
    </footer>
  </article>
</dialog>

<script>
  const html = document.documentElement;
  const duration = 400; // milliseconds

  function openModal(dialog) {
    const scrollbarWidth = window.innerWidth - html.clientWidth;
    if (scrollbarWidth) {
      html.style.setProperty("--femto-scrollbar-width", `${scrollbarWidth}px`);
    }
    html.classList.add("modal-is-open", "modal-is-opening");
    dialog.showModal();
    setTimeout(() => html.classList.remove("modal-is-opening"), duration);
  }

  function closeModal(dialog) {
    html.classList.add("modal-is-closing");
    setTimeout(() => {
      html.classList.remove("modal-is-open", "modal-is-closing");
      html.style.removeProperty("--femto-scrollbar-width");
      dialog.close();
    }, duration);
  }

  for (const button of document.querySelectorAll("[data-target]")) {
    const dialog = document.getElementById(button.dataset.target);
    button.addEventListener("click", () => openModal(dialog));
    for (const close of dialog.querySelectorAll("[data-close]")) {
      close.addEventListener("click", () => closeModal(dialog));
    }
    // Escape: close with the animation
    dialog.addEventListener("cancel", (event) => {
      event.preventDefault();
      closeModal(dialog);
    });
  }
</script>

Used in the Confirmation dialog example.

components/modal.css reads --femto-color, --femto-icon-close, --femto-modal-overlay-backdrop-filter, --femto-modal-overlay-background-color, --femto-scrollbar-width, --femto-spacing and --femto-transition. See Tokens.
