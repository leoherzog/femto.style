Grid

.grid lays its children out in equal columns from 768px, and in one column below.

1
2
3
4
<div class="grid">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <div>4</div>
</div>

Each child gets its own column, so the columns share the width equally. Below 768px, the children stack in one column.

Columns and gaps

.grid reads its columns from --femto-grid-template-columns, which femto sets to one equal column per child from 768px. The gaps between rows and columns are --femto-grid-row-gap and --femto-grid-column-gap, both --femto-spacing by default. To give a grid other columns, set the token on it, in a media query of your own to keep one column on small screens:

/* A narrow first column and a wide second one, from 768px */
@media (min-width: 768px) {
  .grid.sidebar {
    --femto-grid-template-columns: 1fr 3fr;
  }
}

Other layouts

By default .grid makes equal columns, and --femto-grid-template-columns takes any column template. For other layouts, write CSS grid or flexbox rules of your own. Learn CSS Grid explains CSS grid, and CSS Grid Generator, Layoutit and Griddy write grid rules from a layout you draw.
