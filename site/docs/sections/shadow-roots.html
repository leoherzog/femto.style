Customization

Shadow roots

femto declares its tokens on :host as well as :root, so it also styles the inside of a shadow root that loads it.

The host's data-theme picks the scheme there: data-theme="dark" on a web component's host makes its shadow root dark when the component loads femto in it.

A <link rel="stylesheet"> inside the shadow root works with any femto file, and theme and option files load there the same way, after femto:

<my-widget data-theme="dark">
  <template shadowrootmode="open">
    <link rel="stylesheet" href="dist/femto.min.css">
    <link rel="stylesheet" href="css/themes/jade.css">
    <article>
      <h2>A dark card</h2>
      <p>femto styles this card inside the shadow root, in the dark scheme.</p>
    </article>
  </template>
</my-widget>

Constructable stylesheets

A constructable stylesheet (adoptedStyleSheets) needs the text of dist/femto.css or dist/femto.min.css. CSSStyleSheet.replace() and replaceSync() drop @import rules, so a sheet made from the text of css/femto.css would have no rules at all.

One sheet can be adopted by every shadow root that needs femto. In a module script:

<script type="module">
  const sheet = new CSSStyleSheet();
  sheet.replaceSync(await (await fetch("dist/femto.min.css")).text());
  document.querySelector("my-widget").shadowRoot.adoptedStyleSheets = [sheet];
</script>
