Files

femto comes in two forms that style a page the same way: one file in dist/, or the modules it is built from in css/.

Path Contents
dist/femto.min.css, dist/femto.css All of femto in one file, minified and not. Recommended.
dist/femto.colors.min.css, dist/femto.colors.css The color utilities, minified and not.
css/femto.css The entry: it imports the 36 modules with @import, in cascade order.
css/femto.colors.css The source of the color utilities.
css/tokens/, css/layout/, css/content/, css/forms/, css/components/, css/utilities/ The modules.
css/themes/ The 20 theme colors.
css/options/ The 3 options.

Use dist/femto.min.css unless you need the modules. It is about 74 KB, 11 KB gzipped and 10 KB with Brotli.

With css/femto.css, the browser finds the modules only after it has downloaded the entry, then fetches 36 files instead of one, and many small files compress worse than one.

The cost of @import

Medians with a cold cache, in Chrome and Firefox, over emulated links to a local HTTPS server set up like a CDN (2026-10-28 and 29).

Cable (28 ms) 246 / 196 247 / 172 550 / 192

Slow 3G (400 ms) 2525 / 1808 2258 / 1452 5334 / 1820

On a first visit the @import entry costs about 2 extra round trips on HTTP/2 and HTTP/3, and 8 to 9 on HTTP/1.1. Repeat visits, from the cache, take about 19 ms either way.

When to use the modules

Use css/ for a custom module set, which can also go in a cascade layer, or to read and edit the modules. A bundler that inlines @import turns css/femto.css into one file too.
