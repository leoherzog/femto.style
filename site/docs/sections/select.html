Forms

Select

<select> has the style of the other fields, with a chevron at the end.

A required select whose chosen option has an empty value, such as a disabled prompt, shows that option in the placeholder color.

<select name="favorite-cuisine" aria-label="Select your favorite cuisine..." required>
  <option selected disabled value="">
    Select your favorite cuisine...
  </option>
  <option>Italian</option>
  <option>Japanese</option>
  <option>Indian</option>
  <option>Thai</option>
  <option>French</option>
</select>

disabled works as on an input.

Select multiple

With multiple, or a size above 1, the select lists its options, and with multiple femto shades the chosen ones. A select with multiple or any size, even size="1", has no chevron.

<select aria-label="Select your favorite snacks..." multiple size="6">
  <option disabled>
    Select your favorite snacks...
  </option>
  <option>Cheese</option>
  <option selected>Fruits</option>
  <option selected>Nuts</option>
  <option>Chocolate</option>
  <option>Crackers</option>
</select>

Validation states

aria-invalid="true" or "false" gives a select the invalid or valid border color, with no icon. A <small> right after the select takes the matching color.

Great choice! Please select your favorite pizza topping! 
<select
  name="valid"
  aria-label="Favorite pizza topping (valid)"
  aria-invalid="false"
  aria-describedby="valid-helper"
>
  ...
</select>
<small id="valid-helper">Great choice!</small>

<select
  name="invalid"
  aria-label="Favorite pizza topping (invalid)"
  required
  aria-invalid="true"
  aria-describedby="invalid-helper"
>
  ...
</select>
<small id="invalid-helper">
  Please select your favorite pizza topping!
</small>
