Customization

Themes

femto's built-in color is azure, and each of the 19 others is one file in css/themes/.

Load a theme right after femto and before your own stylesheets, and in femto's cascade layer if you use one:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/css/themes/jade.css">
<link rel="stylesheet" href="styles.css">

To see a color on this page and copy the links that load it, use the Theme picker.

A color of your own

A theme file is one :root, :host rule that sets ten theme tokens: --femto-primary, --femto-primary-background, --femto-primary-underline, --femto-primary-hover, --femto-primary-hover-background, --femto-primary-focus, --femto-primary-inverse, --femto-primary-inverse-filter, --femto-text-selection-color and --femto-switch-thumb-box-shadow. That is the same specificity as your own overrides on :root, so a theme loaded after your stylesheet would replace them.

For a color of your own, copy a theme file, such as css/themes/jade.css, and change its values. Where its --femto-primary-inverse is dark, set --femto-primary-inverse-filter to brightness(0) invert(0), so the loading spinner on primary buttons is dark too. Keep the text readable: a primary button's --femto-primary-inverse text sits on --femto-primary-background, and on --femto-primary-hover-background when it is hovered, pressed, focused or current, so give each at least 4.5:1 contrast with it in both schemes.

One request

femto ships no prebuilt themed copies. To fetch femto and a theme in one request, join them in a jsDelivr combine URL:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/combine/npm/@leoherzog/femto@3/dist/femto.min.css,npm/@leoherzog/femto@3/css/themes/jade.css">

This should work once femto is published, because neither file has an @import and every url() in them is a data: URI, but it is not yet confirmed. It does not work with css/femto.css: jsDelivr does not rewrite relative paths in combined files, so the entry's @imports would not resolve.
