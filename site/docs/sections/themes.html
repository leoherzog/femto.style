Customization

Themes

femto's built-in color is azure, and each of the 19 others is one file in css/themes/.

Load a theme right after femto, then any options, then your own stylesheets, and in femto's cascade layer if you use one:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/css/themes/jade.css">
<link rel="stylesheet" href="styles.css">

To see a color on this page and copy the links that load it, use the Theme picker.

A color of your own

A theme file is one :root, :host rule that sets ten tokens (femto's --femto-* custom properties): --femto-primary, --femto-primary-background, --femto-primary-underline, --femto-primary-hover, --femto-primary-hover-background, --femto-primary-focus, --femto-primary-inverse, --femto-primary-inverse-filter, --femto-text-selection-color and --femto-switch-thumb-box-shadow. That is the same specificity as your own overrides on :root, so a theme loaded after your stylesheet would replace them.

For a color of your own, copy a theme file, such as css/themes/jade.css, and change its values:

  • Give --femto-primary-inverse, a primary button's text, at least 4.5:1 contrast in both schemes with --femto-primary-background and with --femto-primary-hover-background, which the button uses when hovered, pressed, focused or current.
  • Where --femto-primary-inverse is dark, set --femto-primary-inverse-filter to brightness(0) invert(0) so the loading spinner on primary buttons is dark too.

One request

femto ships no prebuilt themed copies. To fetch femto, a theme and any options in one request, join them in a jsDelivr combine URL:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/combine/npm/@leoherzog/femto@3/dist/femto.min.css,npm/@leoherzog/femto@3/css/themes/jade.css">

This is expected to work once femto is published, since none of these files has an @import and every url() in them is a data: URI, but it is not yet confirmed. It does not work with css/femto.css, whose relative @import paths jsDelivr does not rewrite.
