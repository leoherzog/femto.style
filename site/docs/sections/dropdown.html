Components

Dropdown

<details class="dropdown"> is a dropdown: a <summary> and a <ul> that opens below it.

The <ul> comes right after the <summary>, both directly inside the <details>. The summary looks like a select, and the dropdown is as wide as its container, except in a nav. A click outside an open dropdown closes it.

aria-current on an item’s link shows it as current, with its hover colors.

Dropdown
  • Solid
  • Liquid
  • Gas
  • Plasma
<!-- Dropdown -->
<details class="dropdown">
  <summary>Dropdown</summary>
  <ul>
    <li><a href="#">Solid</a></li>
    <li><a href="#" aria-current="true">Liquid</a></li>
    <li><a href="#">Gas</a></li>
    <li><a href="#">Plasma</a></li>
  </ul>
</details>

<!-- Select -->
<select name="select" aria-label="Select" required>
  <option selected disabled value="">Select</option>
  <option>Solid</option>
  <option>Liquid</option>
  <option>Gas</option>
  <option>Plasma</option>
</select>

Dropdowns with checkboxes and radios

With <input type="radio"> or <input type="checkbox"> in its items, a dropdown is a custom select.

femto has no JavaScript: to show the choice in the summary or close the dropdown after a choice, use your own script.

Button variants

<summary role="button"> makes the dropdown a button, which takes .secondary, .contrast and .outline like other buttons (see Button).

Usage with <nav>

In a nav, a dropdown is as wide as its summary. <ul dir="rtl"> lines the list up with the summary’s right edge.

  • Acme Corp
  • Services
  • Account
    • Profile
    • Settings
    • Security
    • Log out
<nav>
  <ul>
    <li><strong>Acme Corp</strong></li>
  </ul>
  <ul>
    <li><a href="#" class="secondary">Services</a></li>
    <li>
      <details class="dropdown">
        <summary>
          Account
        </summary>
        <ul dir="rtl">
          <li><a href="#">Profile</a></li>
          <li><a href="#">Settings</a></li>
          <li><a href="#">Security</a></li>
          <li><a href="#">Log out</a></li>
        </ul>
      </details>
    </li>
  </ul>
</nav>
