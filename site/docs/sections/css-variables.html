Customization

CSS variables

Change femto's fonts, spacing, borders and colors by setting its --femto-* custom properties in your own CSS.

These docs call femto's custom properties tokens. Changing one needs no build step.

Set a token in your own stylesheet, loaded after femto: on :root for the whole page, or on a selector for those elements and what is inside them. Load it after any theme and option files, or they can override your values (see Themes).

Some elements set their own values, which an override on :root does not reach. Headings, for example, set their own font size and weight. Set those on the element, as the example below does for h1.

Example

Pacifico is a web font: load it on your page too, or the heading falls back to a cursive system font.

Music fest mania

Get ready to dance and sing your heart out. Join the crowd, jam to your favorite band, and discover new artists.

<style>
  :root {
    --femto-border-radius: 2rem;
    --femto-typography-spacing-vertical: 1.5rem;
    --femto-form-element-spacing-vertical: 1rem;
    --femto-form-element-spacing-horizontal: 1.5rem;
  }
  h1 {
    --femto-font-family: Pacifico, cursive;
    --femto-font-weight: 400;
    --femto-typography-spacing-vertical: 0.5rem;
  }
  button[type=button] {
    --femto-font-weight: 700;
    margin-bottom: 0;
  }
</style>

<h1>Music fest mania</h1>
<p>
  Get ready to dance and sing your heart out.
  Join the crowd, jam to your favorite band,
  and discover new artists.
</p>
<button type="button">Let's rock out!</button>

Tokens and color schemes

femto declares each color token once, on :root, :host, so one override on :root applies inside every data-theme element (see Color schemes). A token that femto or a theme gives a light and a dark value takes them from a pair of tokens of its own, such as --femto-light-primary and --femto-dark-primary for --femto-primary. Set the pair to give each scheme its own value, and set the token itself for one value in both:

:root {
  --femto-light-text-selection-color: rgba(244, 93, 44, 0.25);
  --femto-dark-text-selection-color: rgba(245, 107, 61, 0.1875);
  --femto-light-primary: #bd3c13;
  --femto-dark-primary: #f56b3d;
  --femto-primary-background: #d24317;
  --femto-light-primary-underline: rgba(189, 60, 19, 0.5);
  --femto-dark-primary-underline: rgba(245, 107, 61, 0.5);
  --femto-light-primary-hover: #942d0d;
  --femto-dark-primary-hover: #f8a283;
  --femto-light-primary-hover-background: #bd3c13;
  --femto-dark-primary-hover-background: #bd3c13;
  --femto-light-primary-focus: rgba(244, 93, 44, 0.5);
  --femto-dark-primary-focus: rgba(245, 107, 61, 0.375);
  --femto-primary-inverse: #fff;
}

These are some of the orange theme's values. To change the primary color, load a theme file, or copy one for a color of your own: see Themes.

css/tokens/schemes.css declares every pair. A --femto-light-* or --femto-dark-* name for a token without one, such as --femto-primary-background or --femto-primary-hover-underline, does nothing.

Set a pair on :root. femto combines each pair into its token there and on :host, so a pair set on another element does not change femto's colors. To change a color inside one element, set the token itself on it, such as --femto-primary on a card.

An override written with light-dark(), such as --femto-primary: light-dark(#c00, #f66), also works, except in browsers without light-dark(), where it fails. Those browsers use the light value of each pair, including the ones you set (see Browser support).

The form validation icons, --femto-icon-valid and --femto-icon-invalid, are images, which light-dark() cannot carry, so femto sets them per scheme instead, from --femto-light-icon-valid, --femto-dark-icon-valid, --femto-light-icon-invalid and --femto-dark-icon-invalid. Color schemes lists the other values it switches that way.

A script that reads a color token with getPropertyValue() gets light-dark(...) text for a token declared with light-dark() or set from one with var(), such as light-dark(#0172ad, #01aaff) for the default --femto-primary. To get the color in effect, set the token on a property, such as color: var(--femto-primary), and read that property's computed value.

Where each token is declared

femto declares its tokens' defaults in these files:

  • css/tokens/base.css: the tokens that do not depend on the color scheme, such as the font families, font size and weight, line height, borders, outlines, transitions, spacing, component settings, and the icons that are the same in both schemes.
  • css/tokens/schemes.css: the color tokens, with the pairs that hold their light and dark values, the validation icons of each scheme, and the light scheme that browsers without light-dark() get.
  • css/tokens/breakpoints.css: the root font size at each breakpoint, and --femto-grid-template-columns, the columns .grid reads from 768px.
  • css/layout/elements.css: the values some elements set for themselves, such as each heading's font size, line height and weight.
  • css/components/modal.css: --femto-scrollbar-width, which your modal script can set (see Modal).

A few per-component values, such as --femto-underline and --femto-border-color, are set only in their own modules, with no default in these files.
