Customization

CSS variables

Change femto's fonts, spacing, borders and colors by setting its --femto-* custom properties in your own CSS.

femto reads its settings from custom properties, which these docs call tokens: font families and sizes, line height, spacing, border radius and widths, transitions, and the colors of both color schemes. Every name starts with --femto-, and changing a value needs no build step.

Set a token in your own stylesheet, loaded after femto: on :root for the whole page, or on a selector for those elements and what is inside them. Load theme and option files before your stylesheet, right after femto. A theme file sets its tokens on :root, :host, the same specificity as your :root, so a theme loaded after your stylesheet would replace your values.

Some elements set their own values, which an override on :root does not reach. Headings, for example, set their own font size and weight. Set those on the element, as the example below does for h1.

Example

The heading's font, Pacifico, is a web font that this page loads. Load it on your page too, or the heading falls back to a cursive system font.

Music fest mania

Get ready to dance and sing your heart out. Join the crowd, jam to your favorite band, and discover new artists.

<style>
  :root {
    --femto-border-radius: 2rem;
    --femto-typography-spacing-vertical: 1.5rem;
    --femto-form-element-spacing-vertical: 1rem;
    --femto-form-element-spacing-horizontal: 1.5rem;
  }
  h1 {
    --femto-font-family: Pacifico, cursive;
    --femto-font-weight: 400;
    --femto-typography-spacing-vertical: 0.5rem;
  }
  button {
    --femto-font-weight: 700;
    margin-bottom: 0;
  }
</style>

<h1>Music fest mania</h1>
<p>
  Get ready to dance and sing your heart out.
  Join the crowd, jam to your favorite band,
  and discover new artists.
</p>
<button type="button">Let's rock out!</button>

Tokens and color schemes

Every color token is declared once, on :root, :host, with light-dark() where its light and dark values differ. The visitor's system setting, or data-theme, sets color-scheme, which picks the value in effect (see Color schemes).

So one override on :root applies in both schemes and inside every data-theme element. Write it with light-dark(), the light value first, to give each scheme its own value:

:root {
  --femto-text-selection-color: light-dark(rgba(244, 93, 44, 0.25), rgba(245, 107, 61, 0.1875));
  --femto-primary: light-dark(#bd3c13, #f56b3d);
  --femto-primary-background: #d24317;
  --femto-primary-underline: light-dark(rgba(189, 60, 19, 0.5), rgba(245, 107, 61, 0.5));
  --femto-primary-hover: light-dark(#942d0d, #f8a283);
  --femto-primary-hover-background: #bd3c13;
  --femto-primary-focus: light-dark(rgba(244, 93, 44, 0.5), rgba(245, 107, 61, 0.375));
  --femto-primary-inverse: #fff;
}

These are the orange theme's values. To use a theme color, load its file instead; azure, femto's built-in color, needs none (see Themes). For a color of your own, copy a theme file and change its values. Its ten tokens include --femto-primary-inverse-filter, the filter for the loading spinner on primary buttons: set it to brightness(0) invert(0) when your --femto-primary-inverse is dark.

The form validation icons, --femto-icon-valid and --femto-icon-invalid, are the exception: light-dark() cannot carry an image, so femto sets them per scheme.

A script that reads a color token with getPropertyValue() gets the light-dark(...) text where the schemes differ. To get the color in effect, set the token on a property, such as color: var(--femto-primary), and read that property's computed value.

Where each token is declared

femto declares each token, with its default value, in one of these files:

  • css/tokens/base.css: the tokens that do not depend on the color scheme, such as the font families, font size and weight, line height, borders, outlines, transitions, spacing, component settings, and the icons that are the same in both schemes.
  • css/tokens/schemes.css: the color tokens, with their light and dark values, and the validation icons of each scheme.
  • css/tokens/breakpoints.css: the root font size at each breakpoint, and --femto-grid-template-columns, the columns .grid reads from 768px.
  • css/layout/elements.css: the values some elements set for themselves, such as each heading's font size, line height and weight.
  • css/components/modal.css: --femto-scrollbar-width, which your modal script can set (see Modal).
