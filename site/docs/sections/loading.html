Loading

aria-busy="true" shows a loading spinner before an element’s content.

It works on any element but form fields, <form> and <html>. In an empty element, the spinner is centered. On a block:

<article aria-busy="true"></article>

On an inline element:

Generating your link...
<span aria-busy="true">Generating your link...</span>

On a button, which then ignores the pointer. Give an empty button an aria-label:

<button type="button" aria-busy="true" aria-label="Please wait…"></button>
<button type="button" aria-busy="true" aria-label="Please wait…" class="secondary"></button>
<button type="button" aria-busy="true" aria-label="Please wait…" class="contrast"></button>
<button type="button" aria-busy="true" class="outline">Please wait…</button>
<button type="button" aria-busy="true" class="outline secondary">Please wait…</button>
<button type="button" aria-busy="true" class="outline contrast">Please wait…</button>
