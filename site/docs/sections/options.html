Customization

Options

Each file in css/options/ changes one default.

File What it does
responsive-spacings.css Gives the page's header, main and footer, sections and cards (<article>) more vertical spacing at each breakpoint, and cards more horizontal spacing, from 1.25 to 2.25 times --femto-spacing.
fixed-typography.css Keeps the root font size at 100% at every width, instead of stepping it up at each breakpoint.
no-transitions.css Turns off the transitions of links, buttons, form fields and components; the modal opens and closes without animating, and tooltips appear without sliding in. The loading spinner and the indeterminate progress bar still animate.

These docs load responsive-spacings.css.

Loading an option

Load an option like a theme: after femto and any theme, before your own stylesheets. Each file's header says what it overrides.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/dist/femto.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@leoherzog/femto@3/css/options/fixed-typography.css">
<link rel="stylesheet" href="styles.css">

No transitions

With no-transitions.css, --femto-transition is 0s, so your own rules that read it stop animating too.
