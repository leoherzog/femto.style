Tokens

Every custom property femto declares, but the light and dark pairs, under the section that shows it: what it sets, and whether it has a pair.

femto declares 149 tokens on :root and :host or on the elements that use them, and a light and a dark token for each of the 58 with a pair: 265 custom properties in all. Set one in your own CSS, as CSS variables shows. Where a row says "set on" or "set per", femto sets the token on those elements, so a value on :root does not reach them: set it on the elements.

Each of the 58 tokens with a pair takes its light and dark values from two tokens of its own, such as --femto-light-primary and --femto-dark-primary for --femto-primary (see Color schemes). The validation icons' pairs are switched by the scheme rules instead, since light-dark() cannot carry an image.
